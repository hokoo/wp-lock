The implementation moves public acquire/release to the accepted permanent-resource-row protocol on the independent primary connection. Successful acquisition confirms a committed owner and preserves the auto-increment owner ID; release uses the captured namespace and removes only its predecessor owner. The public wrapper retains held state and owner identity when release fails, so the caller can retry. Public `exists()` distinguishes failed SELECT from proven absence. The implementation uses bounded rollback/retry for a confirmed database deadlock during release and explicit uncertainty handling for INSERT/COMMIT acknowledgment loss and connection loss.
